# AGENTS.md

Site Ops Assistant: RAG over runbooks (`/ask`) + log-triage agent that opens tickets via MCP (`/triage`), uv workspace, Python 3.12, microservices.

## Rules

1. **No code unless explicitly asked.** Explain, plan, update docs or create empty files/folders freely; write implementation code, tests or config contents only when the user asks for it in so many words.
2. **Respect `docs/DECISIONS.md`.** Read it before proposing or writing anything.
   - **Decided** entries are binding. If a request or your own plan conflicts with one, stop and point out the conflict (cite it as `subject/number`, e.g. `arch/4`) instead of working around it.
   - **Proposed** and **Open** entries are not settled. Don't silently pick an answer: say which entry your work depends on and ask, or add/update the entry as **Proposed** with your recommendation.
   - When a new decision is made, record it in `docs/DECISIONS.md` (next free number in its subject, at the end of that section; update the index tables). Never renumber existing IDs.
3. **Keep the file structure below correct.** Whenever you add, move, rename or delete a file or folder, update the tree in this file in the same change. If the tree and the disk disagree, flag it.
4. **No AI attribution in git.** Never add `Co-Authored-By` trailers, "Generated with" lines or any other AI attribution to commit messages or PR descriptions, including in commands you write for the user.

## File structure

**Labels:** **SHARED** wire contracts used by several services (arch/4) · **ENTRY** process entry point · **ROOT** composition root and its config (design/3) · **CORE** own logic, no vendor imports · **FLOW** wires CORE steps and adapters into a framework's graph; the only own code that imports the framework (agent/4) · **INTERFACE + ADAPTERS** a subpackage holding `base.py` (the ABC, design/2) plus ≥2 implementations, one real and one fake (design/1) · **SYSTEM** tests that span services.

Every service has its own `Dockerfile`, built with the repo root as build context (arch/4). `uv.lock` is generated by `uv lock`; never edit it by hand. Every folder under a `src/` folder is a package with an `__init__.py` (not drawn in the tree below); `src/` itself has none.
